# Biblioteca Horizonte - Simulación de Plataforma Web

## Descripción del Proyecto

**Biblioteca Horizonte** es un proyecto de simulación de interfaz web interactiva diseñado para representar el frontend de una biblioteca virtual moderna. La aplicación permite a los usuarios explorar categorías literarias, visualizar contenido multimedia explicativo, revisar libros recomendados y gestionar una selección interactiva de títulos mediante un contador dinámico.

Este desarrollo simula la experiencia de usuario (UX) de una plataforma de descubrimiento y selección de libros en línea, combinando maquetación semántica, diseño adaptativo y lógica interactiva.

## Tecnologías y Herramientas Utilizadas

El desarrollo de esta simulación web se llevó a cabo utilizando las siguientes tecnologías y herramientas estándar de la industria:

* **HTML5:** Estructuración semántica de la página (`<header>`, `<nav>`, `<main>`, `<video>`, entre otros).

* **CSS3:** Estilizado modular y maquetación visual (ubicado en `static/css/style.css`).

* **JavaScript (ES6):** Manipulación del DOM y lógica interactiva para la selección de libros y manejo de eventos (ubicado en `static/js/script.js`).

* **Entorno de Desarrollo:** Visual Studio Code / Editor de código web.

## Estructura del Proyecto

```
biblioteca-horizonte/
├── index.html                  # Archivo principal de la interfaz HTML
└── static/
    ├── css/
    │   └── style.css           # Hojas de estilo y reglas visuales
    ├── js/
    │   └── script.js           # Lógica interactiva y scripts del frontend
    ├── images/                 # Recursos gráficos e imágenes del catálogo
    └── videos/                 # Archivos multimedia (videos promocionales)
```

## Instrucciones de Ejecución

1. **Clonar o descargar** el repositorio o los archivos del proyecto en un directorio local.

2. Mantener la estructura de carpetas indicada (`static/css`, `static/js`, `static/images`, `static/videos`).

3. Abrir el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
